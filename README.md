# Databricks DAB & CI/CD Hands-on

This is a basic hands-on project completed using **Databricks Free Edition** to understand **Databricks Asset Bundles (DABs)** and **CI/CD**.

## What I Learned

* Understood the basics of **Databricks Asset Bundles (DABs)**
* Understood how **CI/CD** works with Databricks
* Created and worked with a sample table
* Created a simple query/code to test the bundle deployment
* Practiced making changes and pushing them through GitHub
* Understood the basic workflow of deploying Databricks resources using DABs

## Tools Used

* Databricks Free Edition
* SQL / PySpark
* Databricks Asset Bundles (DABs)
* GitHub
* Git

## Note

This project was created as a **hands-on learning exercise** to understand DABs, Git-based workflows, and CI/CD deployment in Databricks.
